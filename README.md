# Fly Like the Wind ✈️🌬️

Jeu de vol en 3D dans le navigateur (Vite + Three.js).

## Lancer le jeu
```
npm install
npm run dev
```
Puis ouvrir http://localhost:5173

## Contrôles
- ↑ / ↓ : piquer / cabrer
- ← / → : tourner
- Espace : accélérer — Shift : ralentir

## Modifier le jeu
Tous les réglages faciles (vitesse, couleurs…) sont dans `src/config.js`.

## Déploiement
Vercel détecte Vite automatiquement : build `npm run build`, dossier de sortie `dist`.
